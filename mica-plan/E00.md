# E00 — Can we trust the comparison?

**Goal:** Before comparing speed, make sure every selected format—starting with Mica, Parquet, and Lance—contains the same intended data, answers the same questions correctly, and runs under recorded conditions. If one reader returns different rows, its faster time is not a valid win.

| Step | What to check and why | Existing → needed |
|---|---|---|
| **1. Record the test setup** | Write down the input data, query text, format settings, code version, machine, number of CPU workers, and whether file bytes were already in RAM. This lets someone repeat the run and see whether resources were comparable. | Benchmark controls exist → choose settings, explicitly select Mica v3, and save the run and machine reports. |
| **2. Check the stored data** | Convert the same source rows to each format, then compare values and row order. Otherwise, a speed difference might come from different data or sorting. | An Arrow/Parquet/Lance comparison exists → add Mica to it. |
| **3. Check query answers** | Run the same queries and compare the returned values, nulls, duplicate counts, and order when the query requires it. | A query verifier exists → run it for the chosen setups; its existing nine queries do not prove every possible query is correct. |
| **4. Check awkward cases** | Try empty results, nulls, boundary rows, duplicate values, and damaged/truncated input. Confirm that skipping data never drops a real match. | Some tests exist → check which E00 cases they cover and add only missing ones. |
| **5. Audit older claims** | If reusing old timing numbers, locate their raw runs and exact settings. Recheck reported file sizes, including extra indexes and dictionaries, and the listed paper corrections. | Size-analysis code exists; old raw reports are missing from this workspace → recover them or rerun affected claims, then resolve the paper corrections. |

**Done when:** The chosen setup and raw results are saved, all formats pass the required data and answer checks, and every reused number can be traced to its run. E00 checks trustworthiness; it does not claim a speedup.
